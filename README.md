# bakpak

**Save context. Reuse anywhere.**

BakPak is a lightweight Chrome extension that lets you save context while browsing
and reuse it instantly in ChatGPT, Notion, Docs, or anywhere you work.

## What it does
- Save page context with one click
- Recall and copy context instantly
- Keep your thinking portable
